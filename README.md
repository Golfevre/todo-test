# TODO App

React + TypeScript + Vite で作成したシンプルなTODOアプリです。

## 機能

- タスクの追加・削除
- ダブルクリックでタスクを編集
- 完了・未完了の切り替え（一括切り替え含む）
- フィルター（すべて / 未完了 / 完了済み）
- 完了済みタスクの一括削除
- localStorage によるデータの永続化
- ライト/ダークモード対応

## セットアップ

Node.js (18以上推奨) が必要です。

```bash
npm install
npm run dev
```

`http://localhost:5173` で確認できます。

## ビルド

```bash
npm run build
npm run preview
```
